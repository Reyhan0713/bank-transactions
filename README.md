# Bank Transactions Dashboard

A responsive bank transactions dashboard built with HTML, CSS, and JavaScript.

## Features

- Load and display bank transactions
- Search transactions by tracking ID
- Sort transactions by amount and date
- Format transaction amounts using Persian numerals
- Display income and expense transactions with distinct styles

## Technologies

- HTML5
- CSS3
- JavaScript
- JSON Server

## Getting Started

1. Clone or download the repository.
2. Install the dependencies:

   ```bash
   npm install
   ```

3. Start the JSON Server:

   ```bash
   npm run server
   ```

4. Open `src/index.html` using a local development server, such as VS Code Live Server.

**Note:** The project requires JSON Server to run locally and retrieve transaction data.
